# chest_xray_xai_pipeline

Training, evaluation and explainability pipeline with Grad-CAM for CNN models that classify radiological images, with a focus on the *clinical validation of the models' activations*.

This pipeline was developed as part of a Bachelor's Thesis in Computer Science at the Universidad Complutense de Madrid (UCM), under the supervision of radiologists and medical specialists.

# Overview

This pipeline trains AlexNet and DenseNet-121 at two resolutions (256x256 and 1024x1024) to classify aortic enlargement and cardiomegaly in posteroanterior chest X-rays from the VinDr-CXR dataset. It then generates Grad-CAM saliency maps and validates whether the model's activations converge with clinically relevant anatomical regions.

The methodology is grounded in radiological semiology: every decision — pathology selection, resolution, ground truth, preprocessing, metrics used in validation — is justified from a clinical perspective.

The pipeline has been built to be modular and configuration-driven (config.py)

# Branches

· main: latest stable iteration of the pipeline
· iteration-n: each branch represents a specific iteration, allowing reproducibility of previous experimental results.

# Dataset 

This pipeline has been tested on VinDr-CXR (Nguyen et al., 2022), a chest X-ray dataset with radiologist-annotated bounding boxes. The dataset is not included in this repository due to its size and access restrictions.

# Hardware 

All notebooks are compatible with both CPU and GPU. GPU is strongly recommended for training (notebooks were developed on NVIDIA T4 and L4 via Google Colab). CPU execution is supported but training times will be significantly longer.
